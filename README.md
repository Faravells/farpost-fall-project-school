# Проект для осенней проектной школы от Фарпост
В рамках проектной школы требовалось проанализировать базу данных, содержащую исторические данные об отключениях коммунальных ресурсов (свет, вода и др.) в городе Владивосток. Необходимо было провести исследование данных и разработать новые возможности, которые можно использовать на главной странице сервиса VL-OFF.

### Результаты работы
Во время работы над проектом датасет был подготовлен к анализу (проверены корректность и полнота данных, возможность извлечения из них дополнительных признаков), содержимое датасета изучено и его характеристики представлены с помощью описательных статистик и визуализаций, на основе проведенного анализа разработан небольшой демонстрационный прототип идеи. Также был подготовлен отчет в формате .md c выводами анализа: он содержит описание природы данных, список возможного функционала на их основе и подробное описание выбранной идеи (ценность, необходимость внедрения, обоснование подхода). С процессом анализа можно ознакомиться, скачав файл **"Аналитика отключений систем ЖКХ во Владивостоке.html"** и открыв его в любом браузере, либо скачав файл **"Аналитика отключений систем ЖКХ во Владивостоке.ipynb"** и открыв его в Jupyter. С выводами анализа можно ознакомиться, открыв файл **"Выводы анализа.md"** с помощью GitHub.
